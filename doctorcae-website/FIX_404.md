# Fix "The page could not be found" (404) on Vercel

That 404 usually means **Vercel is looking in the wrong folder** for your site. Fix it in one place: **Root Directory**.

---

## What to do in Vercel

1. Go to **vercel.com** → open **your project** (the one for this website).
2. Click **Settings** (top).
3. In the left sidebar, click **General**.
4. Scroll to **Root Directory**.
5. If it’s **empty** or points to something like the repo root (e.g. the folder that has `doctorcae-website` inside it), change it:
   - Click **Edit** next to Root Directory.
   - Enter: **doctorcae-website**  
     (the folder that contains `index.html`, `api/`, and `package.json`).
   - Save.
6. Go to **Deployments** → click **⋯** on the latest one → **Redeploy**. Wait until it’s done.

After that, your site should load at `https://your-project.vercel.app/` and the Enroll/checkout flow should work (no 404 for the page or the API).

---

## If you don’t see Root Directory

- You must be **inside the project** (click the project name first), then **Settings** → **General**.
- Or open: `https://vercel.com/your-username/your-project-name/settings`  
  and look for **Root Directory** on that page.

---

## If your repo is only the website (no parent folder)

If the GitHub repo has `index.html`, `api/`, and `package.json` at the **top level** (no `doctorcae-website` folder), then leave Root Directory **empty** (or `.`). The 404 is then likely something else; tell me the **exact URL** in the browser when the 404 appears and we can fix that next.
